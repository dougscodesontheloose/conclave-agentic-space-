# Domain Framework — LinkedIn Content Production

**Squad:** sexy_content
**Domínio:** Produção de conteúdo de autoridade para LinkedIn

---

## Framework Operacional: Do Material ao Post

### Fase 1 — Aquisição de Material

**Modo Referência:** usuário fornece URL, texto ou documento.
**Modo Pesquisa:** agente busca ativamente o tema especificado.

Critérios de seleção de material:
- Tem dado numérico verificável? (+)
- Tem paradoxo ou tensão interessante? (+)
- Tem implicação prática para profissionais de tech/dados/estratégia? (+)
- É genérico ou já saturado no LinkedIn? (-)

### Fase 2 — Extração de Pontos-Chave

Do material bruto, extrair:
1. O dado mais surpreendente ou contraintuitivo
2. A citação mais forte (se houver)
3. A implicação prática mais relevante para o público-alvo
4. O paradoxo ou tensão principal

Regra: se não há dado + tensão + implicação, o material não é rico o suficiente. Buscar complemento.

### Fase 3 — Geração de Ângulos

Um ângulo é a perspectiva emocional/intelectual de onde se conta o conteúdo.
O mesmo material gera ângulos completamente diferentes:

- **Ângulo de Dado**: abre com o número de forma inesperada
- **Ângulo Contraintuitivo**: desfaz uma crença óbvia do mercado
- **Ângulo Narrativo**: conta uma história antes de apresentar o dado
- **Ângulo de Implicação**: começa pela consequência, não pela causa
- **Ângulo de Tensão**: apresenta dois lados e escolhe um com clareza

Regra: gerar 3 ângulos distintos. Selecionar 1 com o Doug antes de produzir.

### Fase 4 — Seleção de Formato

| Se o ângulo é... | Melhor formato |
|---|---|
| Um insight rápido e provocativo | Post de texto |
| Um framework ou processo com múltiplas etapas | Carrossel |
| Uma análise profunda com cases e dados | Artigo |
| Uma opinião forte sobre tendência | Post de texto |
| Um guia prático passo a passo | Carrossel |

### Fase 5 — Produção de Conteúdo

**Para posts:** hook + desenvolvimento (dado+narrativa) + CTA reflexivo
**Para carrosséis:** roteiro slide a slide + design posterior
**Para artigos:** título + lead + corpo estruturado + conclusão prática

Regra universal: a ponte entre Tecnologia Fria e Emoção Humana Real deve ser visível em qualquer formato.

### Fase 6 — Design Visual (carrosséis)

Sequência obrigatória:
1. Selecionar pacote visual (baseado no tema)
2. Selecionar paleta (cruzamento não-óbvio com o pacote)
3. Planejar hierarquia de cada slide
4. Renderizar com tipografia de personalidade

### Fase 7 — Revisão de Qualidade

Revisão contra: voz do Doug, ausência de clichês, dado contextualizado, hook que para o scroll.
Veredicto: APROVADO / COM RESSALVAS / REPROVADO.

### Fase 8 — Publicação

Formato do texto ajustado para LinkedIn → publicação via Blotato ou entrega manual.

## Princípios do Framework

1. **Um ângulo por conteúdo** — nunca tentar cobrir múltiplas perspectivas no mesmo post.
2. **Dado antes de opinião** — opinião sem evidência é conteúdo de baixa autoridade.
3. **Especificidade bate generalidade** — "78% dos devs" > "muitos desenvolvedores".
4. **Hook é o produto** — se o hook não para o scroll, o conteúdo não existe.
5. **Formato segue ângulo** — o ângulo escolhido dita o formato ideal, não o contrário.

## Critérios de Seleção de Notícias (quando modo = search)

Para selecionar entre múltiplas notícias encontradas, ranquear por:

1. **Relevância para profissionais de tech/dados/estratégia** (peso 40%)
2. **Dado numérico presente e verificável** (peso 30%)
3. **Potencial de ângulo contraintuitivo** (peso 20%)
4. **Recência** (peso 10%)

Eliminar automaticamente: notícias sem fonte clara, press releases corporativos genéricos, conteúdo já saturado no LinkedIn nos últimos 30 dias.
