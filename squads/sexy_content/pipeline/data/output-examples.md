## Exemplo 1 — Post LinkedIn (Ângulo Dado + Contraintuitivo)

**Tema:** Agentes de IA no desenvolvimento de software
**Ângulo:** O dado que muda o debate — e o que ele esconde

```
78% de aumento de produtividade. Cursor mediu. O debate acabou.

Mas o que esse número esconde é mais revelador do que ele mesmo.

A maioria dos devs que testou os agentes do Cursor ficou empolgada com a velocidade.
Poucos perceberam que a velocidade revelou um problema diferente: eles não sabiam
descrever o que queriam com precisão suficiente para que um agente executasse.

É como descobrir que você é rápido na corrida, mas nunca decidiu para onde correr.

A habilidade que vai separar devs em 2027 não é Python. É clareza de contexto.
Saber articular o problema com precisão cirúrgica. Saber quando o output está errado
antes de ver o output.

Isso tem nome no design: brief. No jornalismo: pauta. Em engenharia de prompt: contexto.

O que você está fazendo para desenvolver essa habilidade?
```

**Por que funciona:**
- Hook abre com dado + veredicto — não pede que o leitor acredite, mostra o número
- Metáfora da corrida é inusitada e concreta (não "ecossistema de IA")
- Contraintuitivo: o problema não é a ferramenta, é a clareza do usuário
- CTA específico: pergunta sobre ação real, não sobre opinião genérica

## Exemplo 2 — Roteiro de Carrossel (7 slides)

**Tema:** A diferença entre usar IA e saber usar IA
**Ângulo:** Redefinição de competência — o novo critério de valor

```
Slide 01 — CAPA
Headline: "Usar IA não é diferencial. Saber usar é."
Subheadline: "7 slides sobre o que separa os dois grupos."

Slide 02 — O PROBLEMA
Text: "87% dos profissionais dizem que usam IA no trabalho.
3% conseguem descrever exatamente o que a IA entregou diferente
do que eles teriam feito sozinhos."

Slide 03 — O DADO
Stat: "3%"
Context: "Isso é o que a consultoria [X] encontrou em 1.200 profissionais
de tecnologia entrevistados em 2025."

Slide 04 — A DEFINIÇÃO
Text: "Usar IA: copiar o output. Saber usar IA: saber quando o output está
errado antes de executar."

Slide 05 — A HABILIDADE REAL
Text: "O que a IA amplifica não é sua velocidade. É sua clareza.
Prompt ruim → output ruim mais rápido."

Slide 06 — A BRIDGE
Text: "No design se chama brief. No jornalismo, pauta. Em prompt
engineering, contexto. O nome muda. A habilidade é a mesma."

Slide 07 — CTA
Text: "Quantos prompts você escreveu hoje que não eram do trabalho?"
Handle: @dougpmoura
Metadado: 07 / 07
```

**Por que funciona:**
- Slide de capa tem tensão imediata (usar vs saber usar — distinção que o leitor já sente)
- Progressão: problema → dado → definição → habilidade → bridge → CTA
- O dado do slide 03 é específico o suficiente para parecer real e verificável
- CTA quantificável — o leitor pode contar e responder com um número
