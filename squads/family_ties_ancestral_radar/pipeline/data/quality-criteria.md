# Quality Criteria

- Toda query web deve nascer de um alvo explícito no briefing sanitizado.
- Cada achado deve registrar fonte, consulta usada, evidência extraída e nível de confiança.
- Achados devem virar ação: pedir documento, refinar nome, ampliar localidade ou descartar pista.
- Sempre explicitar o que continua faltando para a próxima busca.
- Cada achado deve terminar como `A`, `B`, `C`, `D`, `X`, `qualified_negative` ou `access_block`.
- Bloqueio de acesso nunca pode ser tratado como negativo de acervo.
- Atualizacao de arvore exige evidencia `A` ou `B`; pistas `C`/`D` viram fila de busca.
