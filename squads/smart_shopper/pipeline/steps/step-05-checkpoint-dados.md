# Step 05: Checkpoint — Review dos Dados Brutos

## Instructions

Apresentar um resumo consolidado dos 3 relatórios para o usuário avaliar antes do veredito:

1. **Resumo de preços** (top 5 de Priya): Loja, custo total, condições.
2. **Resumo de cupons** (melhores combos de Kira): Loja, economia total.
3. **Resumo de reputação** (scores de Rex): Loja, confiança, red flags.
4. Perguntar ao usuário:
   - **Prosseguir para o veredito** — Os dados estão suficientes.
   - **Refinar pesquisa de preços** — Pedir a Priya que busque em mais lojas ou especifique melhor.
   - **Refinar pesquisa de cupons** — Pedir a Kira que busque em mais plataformas.
   - **Cancelar** — Encerrar a pesquisa.

## Checkpoint Questions

1. Os dados coletados são suficientes para gerar o veredito?
   - Sim, gerar veredito
   - Refinar pesquisa de preços
   - Refinar pesquisa de cupons
   - Cancelar
