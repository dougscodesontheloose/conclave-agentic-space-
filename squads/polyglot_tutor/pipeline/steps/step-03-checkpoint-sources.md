# Checkpoint 03: Fontes e Sequência

Apresente a curadoria antes de transformá-la em plano. O objetivo é evitar que o roteiro seja construído sobre fontes erradas, longas demais ou desalinhadas ao nível.

## O que o usuário deve validar

- As fontes principais são interessantes o bastante para uso real?
- O nível estimado parece adequado?
- Há excesso de material para o tempo disponível?
- A sequência recomendada faz sentido?
- Alguma fonte deve ser removida, substituída ou priorizada?

## Approval Format

```markdown
## Checkpoint: Fontes

Fontes principais:
1. [Fonte] — motivo — uso
2. [Fonte] — motivo — uso
3. [Fonte] — motivo — uso

Sequência recomendada:
1.
2.
3.

Decisão necessária:
- Aprovar fontes
- Cortar fontes
- Trocar foco/nível
```

## Veto Conditions

1. Não avançar se não houver pelo menos uma fonte principal adequada.
2. Não avançar se os materiais excederem claramente o tempo disponível.
3. Não avançar se a curadoria virar dump de links sem sequência.
