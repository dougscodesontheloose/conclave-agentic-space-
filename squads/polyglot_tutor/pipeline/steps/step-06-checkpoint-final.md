# Checkpoint 06: Plano Final

Apresente o plano revisado e o veredito de qualidade. Este checkpoint deve permitir uma decisão prática: executar, ajustar ou arquivar.

## O que o usuário deve validar

- O plano cabe na rotina real?
- A primeira sessão está clara o suficiente para começar hoje?
- A métrica de progresso é mensurável?
- A decisão de progressão ficou clara: repetir, avançar, reduzir ou intensificar?
- Os riscos residuais são aceitáveis?
- O plano deve alimentar algum hub de idioma?

## Approval Format

```markdown
## Checkpoint Final

Veredito:
- Qualidade:
- Riscos residuais:
- Primeiro passo:
- Métrica:
- Progressão:

Decisão necessária:
- Executar plano
- Ajustar antes de executar
- Exportar para hub
```

## Veto Conditions

1. Não entregar como final se o veredito da revisão for `REJECT`.
2. Não entregar como final se não houver primeiro passo executável.
3. Não exportar para hub sem blocos exportáveis.
4. Não entregar sessão de estudo sem decisão de progressão.
