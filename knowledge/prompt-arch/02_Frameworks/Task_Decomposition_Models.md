# Modelos Prompts Decomposição de Tarefas

### Modelo 1 – Peça para quebrar antes de executar

```
Quero resolver o seguinte problema: [DESCREVA].

Antes de propor a solução, divida essa tarefa nas etapas necessárias.

Explique o objetivo de cada etapa.

Depois execute cada etapa em ordem.
```

---

### Modelo 2 – Forçar pensamento estruturado

```
Analise o seguinte desafio: [DESAFIO].

Primeiro: quebre o problema em componentes menores.
Segundo: identifique dependências entre eles.
Terceiro: organize em ordem lógica de execução.

Só depois apresente a solução consolidada.
```

---

### Modelo 3 – Para decisões estratégicas

```
Preciso decidir sobre [TEMA].

Divida essa decisão nos critérios relevantes.

Avalie cada critério separadamente.

Compare os resultados.

Só então apresente a recomendação final.
```

---

### Modelo 4 – Para projetos grandes

```
Quero executar [PROJETO].

Antes de montar o plano, decomponha em:
1. Fase de diagnóstico
2. Fase de planejamento
3. Fase de execução
4. Fase de validação
5. Fase de otimização

Explique o que entra em cada fase.
Depois detalhe o plano completo.
```

---

### Modelo 5 – Versão mais simples e poderosa

```
Não entregue a solução direto.

Primeiro divida o problema em partes menores.
Depois resolva parte por parte.
Só então consolide o resultado final.
```

---

### Extra – Versão mais sofisticada (consultor sênior)

```
Atue como um consultor sênior.

Antes de responder, decomponha o problema usando raciocínio estruturado.

Identifique variáveis, riscos e interdependências.

Só então apresente a recomendação.
```
