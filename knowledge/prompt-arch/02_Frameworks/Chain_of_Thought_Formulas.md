> Modelos Prompts Chain Of Thought
> 
> 
> 
> ### **FÓRMULA 1: A Quebra Estruturada**
> 
> ```
> [Sua pergunta ou tarefa]
> 
> Divida isso passo a passo:
> 
> 1. [Primeiro ponto a considerar]
> 2. [Segundo ponto a considerar]
> 3. [Terceiro ponto a considerar]
> 4. [Recomendação/resposta final]
> ```
> 
> ### **FÓRMULA 2: A Cadeia de Raciocínio**
> 
> ```
> [Sua pergunta ou tarefa]
> 
> Pense nisso de forma sistemática:
> 
> - O que estamos realmente tentando resolver?
> - Quais fatores mais importam?
> - Quais são as trocas (trade-offs)?
> - Qual é a melhor abordagem considerando tudo isso?
> ```
> 
> ### **FÓRMULA 3: O Framework de Análise**
> 
> ```
> [Sua pergunta ou tarefa]
> 
> Analise assim:
> 
> - Identifique o problema central
> - Liste restrições e requisitos
> - Avalie abordagens possíveis
> - Recomende a melhor solução com a justificativa
> ```
> 
> ### **FÓRMULA 4: O Protocolo de Destrinchamento de Problema**
> 
> ```
> [Seu problema]
> 
> Faça o debug de forma sistemática:
> 
> Qual é o comportamento esperado vs. o comportamento real?
> Onde o problema está acontecendo?
> Quais são as causas mais prováveis?
> Qual é a correção mais eficiente?
> Como evitar isso no futuro?
> ```
> 
> ### **FÓRMULA 5: A Matriz de Decisão**
> 
> ```
> [Sua decisão]
> 
> Avalie essa decisão assim:
> 
> - Liste todas as opções realistas
> - Defina critérios de sucesso
> - Dê uma pontuação para cada opção com base nos critérios
> - Identifique riscos nas melhores opções
> - Faça uma recomendação com justificativa
> ```
