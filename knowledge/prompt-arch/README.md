## 🔒 Segurança e Privacidade
Este ambiente está configurado com `.noindex` e `.gitignore` para garantir que o seu conteúdo permaneça privado e local.

## 🚀 Como Usar
Para carregar um prompt, basta navegar na pasta `03_Library/Prompts` e selecionar a técnica desejada. Se estiver trabalhando em um novo agente, use os comportamentos definidos em `01_Agents` como base.
