# Análise Descritiva

Categoria: Análise de Dados

## Prompt

<aside>

Com base nos dados fornecidos, faça uma análise descritiva completa. Inclua:

- O período de tempo que os dados cobrem.
- O número total de vendas, clientes únicos e o valor total vendido.
- A distribuição de vendas pelas categorias existentes na base de dados
- Para as colunas numéricas como o valor de vendas, me dê as principais estatísticas: média, mediana, mínimo, máximo e desvio padrão.
- Verifique se existem valores ausentes (missing values) e em quais colunas.
</aside>
