## Prompt base para infográficos

“Quero um infográfico em formato [16:9 / vertical / quadrado] com visual [polished editorial / técnico / whiteboard desenhado à mão] para resumir um relatório de [tipo de relatório: financeiro, marketing, produto, pesquisa].

Fonte dos dados: vou fornecer [PDF / texto / tabela] contendo métricas como [ex.: receita, crescimento, margem, KPIs de marketing, NPS].

Objetivo: tornar os principais insights imediatamente claros para um público de [executivos / time técnico / clientes], destacando tendências, comparações e pontos de atenção.

Estrutura visual desejada:

- Seção de título com o nome do relatório e período analisado.
- Uma área principal com 2–3 gráficos (ex.: ‘Revenue Growth’, ‘Net Income’, ‘Leads vs. Conversão’, ‘Crescimento por canal’), com rótulos legíveis.
- Blocos de texto curtos com bullet points para “Key Highlights” e “Takeaways”.
- Um box de destaque com uma frase-chave ou citação importante do relatório entre aspas.
- Paleta de cores alinhada ao estilo de [marca X] e fundo limpo para leitura.

Regras de renderização de texto:

- Todos os textos devem estar perfeitamente legíveis, com hierarquia clara entre título, subtítulos e labels de eixos.
- Use tipografia consistente em todo o infográfico.
- Garanta que números e porcentagens fiquem nítidos mesmo em resolução alta.

Composição e qualidade:

- Layout equilibrado, evitando poluição visual.
- Use ícones ou pequenos elementos gráficos apenas para reforçar a leitura dos dados.
- Gere em alta resolução adequada para uso em apresentação e impressão (2K ou 4K, se possível).”

Se você quiser, dá para adaptar esse mesmo molde para: relatório de campanha de marketing, dashboard quarterly tipo earnings report da Alphabet , ou resumo visual de um case de dados.[x](https://x.com/GoogleAIStudio/status/1994480371061469306)
