## <a id="papelaria"></a>Papelaria e escrita analógica

### Hierarquia ativa de ferramentas

- **Canetas-tinteiro:** TWSBI Eco (foco atual), Lamy (AL-Star, Safari Vista, 2000).
- **Lapiseiras mecânicas:** Kuru Toga (Metal, Advance Upgraded), Rotring (600, 800), Pentel GraphGear 500 (0.3/0.5/0.7/0.9), Sharp P200 (baseline de comparação), Pentel Flexfit (0.5), Faber-Castell TK Fine Vario L (0.7/0.9).
- **Cadernos:** Hobonichi Techo, Jibun Techo Biz.
- **Canetas esferográficas/gel:** Uni-ball ZENTO.

### Critérios de escolha

- Tinta preta intensa.
- Papel ≥85 g/m² (ideal). Piso: ~70 g/m² — abaixo disso ocorre ghosting, sangramento e show-through.
- Pontas EF/F. Tintas de baixo fluxo. Tolera manchas.
- **Multipens:** apenas Pentel, Uniball, Zebra ou Pilot. Prefere tinta gel.

### Planners

- **Jibun Techo Biz** para uso diário com fountain pen (papel MIO, secagem rápida, menos ghosting).
- **Hobonichi Cousin** para layouts criativos e BuJo visual.

### Alvos de compra

## Workflow com IA

### Padrão típico

Pesquisa multi-camada → análise → comparação → recomendação.

Variante para conteúdo:
Video → transcript → resumo → key insights.

Variante para ferramentas:
Tool discovery → feature comparison → implementation guidance.

### Características

- Prefere respostas completas e thorough em vez de iteração excessiva.
- Heavy reliance em IA para coleta antes de formar opinião.
- Documenta tudo para referência futura.
- Combina múltiplas IAs com propósitos distintos; experimenta ferramentas novas; compara features ativamente.
- Perfil bilíngue confortável (PT/EN). Direto e eficiente em perguntas. Pede extensões e análise mais profunda além dos achados iniciais.
